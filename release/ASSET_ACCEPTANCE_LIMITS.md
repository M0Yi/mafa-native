# 素材与音频验收边界

本次收尾优先操作页面，只抽查代表场景与已知卡点，不要求逐张检查全部地图。以下限制不因自动回归通过而消失。

- **贴图替代**：`game/content/2011/finish-fallbacks.json` 登记缺失引用及替代关系，属于单机视觉适配。中性地面或石块不代表缺失建筑的原始外形、用途已确认；替换不改变通行数据。
- **解码与视觉**：已有 `artifacts/closeout-full-png-decode.json` 记录98个库、985709帧的解码检查无错误。它证明该次扫描的包、边界与PNG内容可读，不能证明贴图位置、遮挡、动画或当前全部引用已人工核对。
- **技能画面**：当前源码23项技能中17项接入至少一个原帧通道、3项被动、3项尚缺映射（困魔咒、地狱火、地狱雷光）。灵魂火符飞行段缺失，灭天火仍是参考适配，护盾类有帧数依据冲突；部分接入不等于完整还原。详见[技能修复记录](../docs/SKILL_EFFECTS_REPAIR.md)，下载预览包尚未重打包，不等同当前源码。
- **安全区标记**：目前为本地绿色范围覆盖；正版素材及帧映射未确认，不作为原版特效复刻交付。
- **技能声音**：`SKILL_AUDIO_SOURCE_EVIDENCE.json` 对照十周年与十六周年声音索引。beam、manafire各找到一个阶段的声音，其他列出的阶段索引未找到。来源不足不能推断为原版刻意静音，也不能用普通点击声冒充已还原；实际听感与动作同步仍待验收。
- **退出音频**：当前引擎存在独立音频路径退出残留复现，见[AUDIO_EXIT_DIAGNOSIS.md](AUDIO_EXIT_DIAGNOSIS.md)。播放器清空或进程退出0均不等于清洁释放。该退出复现也不等于已经证明游戏运行中持续内存增长。
- **发布内容**：源码与应用不随包附带客户端原始或转换素材。用户在本机提供客户端并生成缓存；源码清单校验不是最终归档检查的替代。

实际结果以[操作页面验收表](UI_ACCEPTANCE.md)和对应原始日志为准；尚未完成的视觉、听音、实体手柄、跨平台及长时间测试继续保留。
