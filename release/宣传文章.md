# 回到玛法，按自己的节奏冒险

还记得第一次走出新手村吗？一把木剑、一件布衣，村外的怪物，还有下一段旅程。

《玛法 · 火龙神殿》把这份经典像素冒险带回本机。它是一款社区制作的单机重建项目：自己创建角色，从村庄委托出发，学习技能、整理装备、穿过熟悉的城镇，把每一次探索留在自己的存档里。

## 保留熟悉，也让操作顺手

键鼠玩家可以使用 WASD 移动、点击寻路，打开背包管理物品。拿起手柄，则有独立的背包、装备、技能和任务操作面板，用肩键来回切换，不必反复移动鼠标。

技能仍需通过技能书学习。希望减少重复操作时，可以自行开启补给、脚下拾取和职业辅助：法师补魔法盾、战士使用刺杀、道士自疗与护甲。辅助遵守已学技能、等级、消耗和冷却，不会凭空授予技能；所有自动行为默认关闭。

## 程序与你的素材分开

这次发布最重要的变化，是程序不再携带热血传奇客户端素材。首次启动时，由你选择自己准备的适配客户端目录，程序在本机读取并转换，生成独立缓存。原始文件不会被修改，客户端 EXE 也不会被执行。

基础素材适配 2.0.1.11 十周年客户端；十六周年目录可用来补充部分缺失素材。完成导入后，游戏进度、资源缓存与程序彼此独立，正常单机流程无需联网。

## 三个平台，同一段旅程

本次提供 macOS Apple Silicon、Windows x86_64 和 Linux x86_64 预发布构建。中文字体和数据库依赖随程序提供，不要求玩家自己搭建服务端或安装 Python。

这是基于现有玩法收尾的预发布，不是历史官方版本的完整复刻。部分场景素材仍有替代，Windows/Linux 的实际显卡与声音体验仍需要硬件验证，实体手柄操作和长时间稳定性也尚未完成验收；局域网联机尚未实现。我们希望把已经做好的内容交到你手上，也把边界说清楚。
